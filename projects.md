## Online Store PHP Project

A database-driven online store project built with PHP and MySQL. The project includes separate customer and employee workflows.

### Features

- Session-based authentication
- Product browsing by category
- Shopping cart functionality
- Checkout using database logic
- Order history
- Employee login
- Stock and price updates
- Product history tracking
